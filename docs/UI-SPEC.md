# UI 사양: 레벨별 기록표 (모바일 우선)

4단계 화면 작업의 기준. 서버 화면과 폰용 단일 HTML이 같은 프론트 코드를 쓴다.

## 전체
- 안드로이드 세로 화면(폭 360~430px) 기준, 다크 테마. 데스크톱에서는 타일 열 수만 늘린다.
- 색: 배경 `#0E1014`, 카드/버튼 배경 `#171A20`, 테두리 `#2A2E36`, 본문 글자 `#E8EAEE`, 보조 글자 `#A3A9B4` / `#8A909C`
- 글꼴: 한글/본문 IBM Plex Sans KR, 숫자·등급·레벨 Barlow Condensed (Google Fonts).
  폰용 단일 HTML은 오프라인이므로 글꼴이 없으면 `system-ui`로 자연스럽게 대체.

## 화면 구성 (위에서부터)
1. **헤더**: 왼쪽 "P-ARCHIVE", 오른쪽 게임 ID(예: `PLAYER #0000`).
   아래 상태 줄: 점 + "오프라인 · 10/30 13:55 기준"(스냅샷 생성 시각), 오른쪽에 믹스 이름(Phoenix 2).
2. **SINGLE / DOUBLE 전환**: 버튼 2개, 가로 반반, 높이 44px.
   - 선택된 SINGLE: 테두리 `#F2603C`, 배경 `#3A1A12`, 글자 `#FFB49E`
   - 선택된 DOUBLE: 테두리 `#3DBE6A`, 배경 `#12301D`, 글자 `#9BE8B4`
   - 선택 안 된 쪽: 기본 카드색
3. **레벨 칩**: 가로 스크롤, 둥근 알약 모양, 최소 44×44px. 선택된 칩은 밝은 배경(`#E8EAEE`)에 어두운 글자.
4. **요약 카드**: "S 21 클리어  9 / 15"(클리어 수 / 그 레벨 전체 채보 수).
   그 아래 4칸 그리드로 등급대별 개수(SSS, SS, S, AAA 이하).
5. **자켓 타일 그리드**: 한 줄 5개, 좌우 여백 12px, 간격 가로 6px·세로 10px.
   - 정사각형 자켓, 모서리 8px
   - 자켓 아래쪽 반투명 띠에 등급(SSS+ 등), 오른쪽 위 작은 배지에 플레이트(PG~RG)
   - 실패(브레이크오프): 등급 자리에 F(빨강 `#FF8A8A`), 배지에 BREAK
   - 자켓 아래 곡명(11px, 한 줄 말줄임), 그 아래 점수(13px, 예: 987,654)
   - 기록 없는 채보: 투명도 0.35, 점수 자리에 "기록 없음"
6. **맨 아래 안내**: "기록 갱신은 PC에서 · 이 파일은 마지막 스냅샷을 보여줘요"

## 등급/플레이트 색
- 등급: SSS+, SSS `#F5C542` / SS+, SS `#E6D29A` / S+, S `#9FD5FF` / AAA+, AAA `#8BE3A8` / 그 이하 `#C9CDD4`
- 플레이트: PG·UG `#F5C542` / EG·SG `#9FD5FF` / MG·TG `#8BE3A8` / FG·RG `#C9CDD4`
- 등급 컷은 Phoenix 2 기준(piu-rough-game `docs/DOMAIN.md`):
  SSS+ 995,000 · SSS 990,000 · SS+ 985,000 · SS 980,000 · S+ 975,000 · S 970,000 · AAA+ 960,000 · AAA 950,000 ·
  AA+ 940,000 · AA 920,000 · A+ 900,000 · A 800,000 · B 700,000 · C 600,000 · D 500,000 · F 0
  (C/D는 확인되지 않은 잠정값). 등급은 piugame이 준 값을 그대로 쓰고, 컷은 검증·통계용으로만 쓴다.

## 동작
- 레벨 칩과 SINGLE/DOUBLE 선택은 새로고침 없이 페이지 안에서 바뀐다.
- 마지막으로 본 레벨/타입은 브라우저 저장소에 기억한다. 저장소가 막혀도 화면은 정상 동작.
- 버튼은 실제 `<button>`, 터치 영역 최소 44px.

## 나중에 붙일 후보 (지금은 만들지 않음)
- 점수를 자켓 위쪽 띠에 크게 표시하는 방식
- 레벨 안 세부 구역 나누기(서열표 데이터 활용)
- 격자/목록 보기 전환, 곡명 표시 on/off
